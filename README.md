This repository contains the source code of my professional portfolio:

### [youssef-bt.github.io](https://youssef-bt.github.io/)

I am a **State Engineer in Data Science** focused on **Artificial Intelligence, Computer Vision, Machine Learning, Controlled RAG and MLOps**.
